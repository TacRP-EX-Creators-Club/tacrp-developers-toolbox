# TacRP Developer's Toolbox

## Spreadsheet

Run `lua_openscript_cl toolbox/gen_spreadsheet.lua` in-game to generate the spreadsheet in garrysmod/data/tacrp_weaponstats.html.dat

Symlink or copy it to spreadsheet_habitat/tacrp_weaponstats.html then view it in a broswer (you may need a webserver)
